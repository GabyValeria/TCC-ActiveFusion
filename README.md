Uma plataforma web para impulsionar seu estilo de vida saudável, combinando calculadoras fitness e uma rede social motivadora.

## 📖 Sobre o Projeto

O **ActiveFusion** é uma plataforma web inovadora, criada para ser a sua parceira ideal na jornada por um estilo de vida mais ativo e saudável. O projeto, desenvolvido como Trabalho de Conclusão de Curso em Informática para Internet, une ferramentas práticas de saúde com o poder de uma comunidade engajada.

O objetivo principal é oferecer um ambiente digital completo onde os usuários podem não apenas monitorar seu progresso físico com precisão, mas também encontrar motivação, compartilhar experiências e se conectar com pessoas que têm os mesmos objetivos.

## ✨ Principais Funcionalidades

###  calculadora Calculadoras Especializadas

Forneça aos usuários ferramentas acessíveis e precisas para autoconhecimento corporal e planejamento de metas.

* **IMC (Índice de Massa Corporal):** Avalie a relação entre peso e altura.
* **TMB (Taxa de Metabolismo Basal):** Descubra o gasto calórico mínimo do seu corpo em repouso.
* **Percentual de Gordura Corporal:** Monitore sua composição corporal de forma estimada.
* **Gasto Calórico Diário:** Calcule suas necessidades calóricas com base no seu nível de atividade.
* **E outros indicadores essenciais** para o acompanhamento do desempenho físico.

### 🌐 Rede Social Fitness

Crie um ecossistema de apoio e motivação mútua para manter todos no caminho certo.

* **Perfis Personalizados:** Crie seu espaço, adicione fotos e descreva seus objetivos.
* **Compartilhamento de Rotinas:** Publique seus treinos e inspire outros membros.
* **Registro de Conquistas:** Marque seus progressos e celebre cada vitória.
* **Interação Social:** Curta, comente e siga outros usuários para criar conexões.
* **Grupos de Interesse:** Participe de comunidades focadas em modalidades específicas (corrida, musculação, yoga, etc.).
* **Eventos Online:** Junte-se a desafios e eventos para se manter engajado.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com uma base sólida de tecnologias web consolidadas, garantindo uma experiência interativa, segura e de fácil navegação.

## 🚀 Como Executar o Projeto

Para rodar o ActiveFusion em seu ambiente local, siga os passos abaixo.

### Pré-requisitos

* Um ambiente de servidor local (ex: XAMPP, WAMP, LAMP).
* Um editor de código (ex: VS Code).
* Git instalado (opcional, para clonar o repositório).

### Instalação

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/GabyValeria/TCC-ActiveFusion.git](https://github.com/GabyValeria/TCC-ActiveFusion.git)
    ```
2.  **Mova a pasta do projeto** para o diretório raiz do seu servidor local (ex: `htdocs` no XAMPP).

3.  **Crie o banco de dados:**
    * Abra o `phpMyAdmin` (ou seu cliente MySQL de preferência).
    * Crie um novo banco de dados chamado `activefusion_db`.
    * Importe o arquivo `activefusion.sql` (que deve estar na pasta `/database` do projeto) para criar as tabelas e inserir os dados iniciais.

4.  **Configure a conexão:**
    * Navegue até o arquivo de configuração do banco de dados (ex: `/config/db.php`).
    * Altere as credenciais (`host`, `username`, `password`, `dbname`) para corresponder às do seu ambiente.

5.  **Inicie o servidor:**
    * Inicie os módulos Apache e MySQL no painel de controle do seu servidor local.

6.  **Acesse a plataforma:**
    * Abra seu navegador e acesse `http://localhost/TCC-ActiveFusion`.
