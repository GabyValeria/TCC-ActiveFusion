# TCC-ActiveFusion
O ActiveFusion é uma plataforma web desenvolvida como Trabalho de Conclusão de Curso em Informática para Internet, com foco na promoção de um estilo de vida saudável por meio da tecnologia. Um dos principais diferenciais do sistema é a integração de calculadoras especializadas voltadas à área fitness e de saúde.

Essas ferramentas permitem que os usuários realizem cálculos personalizados, como IMC (Índice de Massa Corporal), TMB (Taxa de Metabolismo Basal), percentual de gordura corporal, gasto calórico diário, entre outros indicadores essenciais para o acompanhamento do desempenho físico e o planejamento de treinos e dietas. As calculadoras foram integradas ao sistema com o objetivo de fornecer informações práticas e acessíveis, facilitando o autoconhecimento corporal e promovendo decisões mais conscientes em relação à saúde.

Além disso, o ActiveFusion funciona também como uma rede social fitness, onde os usuários podem criar perfis personalizados, compartilhar rotinas de treino, registrar conquistas, interagir com outros membros, participar de grupos de interesse e eventos online. Essa funcionalidade promove motivação mútua, senso de comunidade e suporte contínuo entre os usuários.

Todo o desenvolvimento foi feito com HTML, CSS, JavaScript, PHP e MySQL, garantindo uma experiência interativa, segura e de fácil navegação.
